Architecture this family needs: two tiers. Tier A is numpy on the build-1 STFT framework: HPSS, centre mask, Leveler, the limiter, Streaming Preview, Find Similar. Tier B is neural, behind a `cumple[separate]` extra reusing onnxruntime from the `vad` extra. Keep the STFT outside the network (demucs.onnx pattern) so separators share cumple's STFT front end. Streaming needs two passes: Demucs normalises with the whole track's mean and standard deviation (`api.py` lines 269 to 271), so pass 1 collects stats; inference then runs on fixed segments (7.8 s maximum for htdemucs) with 25% overlap and triangular overlap-add weights (`apply.py`). Rebalance must null at 0 dB: put the residual (mix minus sum of stems) into "other". Weights downloaded, never bundled: fetch on first use, pin SHA-256, record each weights licence in a manifest. Mac realism: onnxruntime has no Intel-Mac wheel (repo commit e1d3bb9), so Tier B degrades gracefully there; on the M1 Pro, CPU or CoreML for htdemucs is plausible; estimate: 600 to 900 MB RoFormers will not be interactive on CPU, not measured.

Unknowns: runtimes on this Mac not measured; weights licences for htdemucs, Spleeter, the RoFormers and BandIt Plus not stated anywhere found; whether CC-BY-SA weights can sit beside MIT code needs 02d's ruling; Open-Unmix's MUSDB SDR not read; whether RX's Streaming Preview is real time or render-only; fdk-aac licence text not read; whether Spotify's real Vorbis settings match libsndfile's quality scale; Rubber Band's latest upstream date (GitHub mirror shows 2025-03-03).

Recommendation from this angle: cheap wins are Streaming Preview, Loudness Control (plus a true-peak limiter), Leveler, Deconstruct, Center Extract, Find Similar, and Time, Pitch and Variable via Signalsmith Stretch; no new heavy dependency. Defer the neural separators (Music, Scene, Dialogue) and Repair Assistant's chain generation until weights licences are ruled on and Tier B is benchmarked on this Mac; htdemucs (MIT, 84 MB) is the only top-quality separator whose weights path is close to clean.

SUMMARY: about half the family can be built in numpy or with existing tools; the neural separators are blocked by weights licences more than code licences. CONCERNS: model runtimes unmeasured; several weights licences unstated or share-alike.
